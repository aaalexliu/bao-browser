# Bao verification map

Read the skill's safety boundary first. Use local fixtures, temporary HOME and Library, pinned Chromium, synthetic source profiles, and a unique UI browser session. These checks need no model account or macOS privacy grant.

- [Agent recording](live-session.md): native pass-through commands, run records, screenshots, and cleanup.
- [Workflow replay](replay.md): retired-driver refusal and separate ordinary replay paths.
- [Library](library.md): empty, saved, search, and historical workflow display.
- [Runs](runs.md): command records, output, screenshots, and final status.

Keep screenshots, page snapshots, command/results, and independent stored-state checks outside the checkout. Label every entry point proved and every one not exercised. A fixture pass does not prove real-site behavior, native permission flows, extension installation, sync, or the whole app.
